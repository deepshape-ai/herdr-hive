Bee v0.3.1 makes the Hive panel more compact and easier to read.

- Bee cells have shorter borders, closer spacing and solid interiors for
  readable text in translucent terminals.
- Each cell shows the Bee name, shared-session count and session names. Your
  device keeps its gold outline; stale directory data remains explicitly marked.
- The layout adapts from three columns to one as the panel narrows, preserving
  long device and session names through wrapping and scrolling.

Compatibility: Herdr 0.9.0 and existing Hive installations. This update changes
only the Bee panel display; sharing, permissions and remote terminal control
are unchanged. Close and reopen an existing Bee panel to see the new layout.
